# 文筆屋さん

bunpitsuya.com ／ 文章を「書く」のではなく「仕立てる」店。

## 何を売るか

お題を渡すと、店が **1 お題を解く → 2 仕入れ → 3 芯 → 4 裏紙 → 5 構成 → 6 一筆目 → 7 見直し → 8 仕上げ**
の八つの工程を、途中を全部見せながら通して、一本の文章に仕立てる。
月額のサブスクで、月あたりの仕立て本数に上限を置く。

## ほかの「AIが書く」道具と何が違うか

1. **仕上げを最後までやる**。AIっぽさ（否定→肯定の型、三つ並べ、太字の決め台詞、進行の実況、
   均一な文の長さ）を**数えて、直して、数え直す**。直したふりで終わらせない。
2. **書き手の台帳**を持てる。一人称・確定している事実・避ける言い回しを台帳に置き、
   連載を書いても人格がぶれない。
3. **仕入れを絞る**。既定は手持ちの材料だけ。実在の人物や数字を出すときだけ、裏取りのために
   最小限だけ調べる。だから一本あたりの原価が安い。
4. **APIキーが要らない**。券を買えば動く。

## 中身

- `core/recipe.md` ── 1〜8の工程の原本。アプリのシステムプロンプトはこれから生成する。
- `core/checks.md` ── 見直し・仕上げで使う点検表。
- `core/ledger-template.md` ── 書き手の台帳のひな型。
- `product/pricing.md` ── 料金。
- `product/ui-notes.md` ── 画面の観察メモ（何を残し、何を変えるか）。
- `product/mvp.md` ── 画面の三状態、1週目／2週目の範囲、技術。
- `product/mock.html` ── 画面の下書き（静的）。焼けた銅と緑青のトーンで確定。
