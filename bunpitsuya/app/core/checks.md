# 点検表

## 見直しの五つの目

感想を書かない。**箇所を名指し、原文を引く。**

### 1. 芯はどこで弱まるか
- 芯が具体で支えられている箇所と、支えを失っている箇所を分けて名指す。
- とくに**終盤の留保**。芯の急所（本当に効くのか、確かめられるのか）に触れる留保が続くと、
  読む人は「結局わからないんだな」で持ち帰る。
- 不利な材料は、迷いとして放置されているか、芯の土台に作り替えられているか。放置なら書き直す。

### 2. 脇道
- 芯に奉仕していない段落を特定する。
- 「影」として残すと決めたものは残してよい。ただし一段落を割いて前に出ていないか。出ていれば一言に落とす。

### 3. 読み違え
- 抜き出したときに芯を条件つきにしてしまう一文を探す。
- 「〜とも言い切れません」の類は、そこで止めず、なぜそれでも芯が立つかまで書き切る。

### 4. 運びの崩れ
- 折り目は一箇所に絞れているか。二箇所以上なら往復になる。
- 二倍ダッシュ（——）の残存
- 説明なしに出る固有名・業界語
- 100字を超える頭でっかちな文
- 同じたとえの一文内での反復

### 5. 事実・因果・効能の断定
- 属性や診断を読む人に断定している文（「あなたは〜だ」「〜な人は必ず〜」）
- 治る・改善する・効く、など効果を約束する語
- 「〜だから〜になる」の因果を根拠なしに一般化している文
- 「ゼロにした」「必ず」「絶対」などの誇大
- 医学・法律・金銭の助言を、専門家でない話者が断定している箇所
見つけたら、主語を書き手の体験に戻すか、削る。

## 文書そのもの（仕立て②）の物差し

手紙・挨拶・告知など、文書そのものを差し出す場合は上の五つの目を使わない。
**その文書として生きているか**で読む。

### 1. 声が割れていないか
説明する声が、語りかける声の上に乗っている箇所を名指す。「なぜこの言葉が効くか」の注釈、
概念の対比の図式化、問いを立てて論駁する運び。混じった瞬間、隣に座っていた人が一歩引いて分析を始めたように読める。

### 2. 話者が動いていないか
「お題を解く」で決めた話者から外れた文を探す。一箇所でも外れると、誰の言葉でもなくなる。

### 3. 具体が報告になっていないか
同じ長さの場面が横に並んでいたら、それは描写ではなく事例の列挙。ひとつかふたつに絞り、
その分だけ細部（音・匂い・体の動き）を厚くする。

### 4. 外形が壊れていないか
文書の体裁に属さないもの（末尾の参照欄、見出しつきの出典一覧、本文から浮いた強調）が付いていないか。
付いていれば外すか、地の文に溶かす。

## 仕上げの表

**実際に数える。そして数えたら直す。**

- [ ] **否定→肯定の型**（「Aではない。Bだ」）の回数 → 6以上なら2に絞る。他は言い切りか具体に開く
- [ ] **「という」**の回数 → 20超なら札貼りが目立つ。半分は直接つなぐ
- [ ] **三つ並べ**（名詞を三つ列挙して締める）の回数 → 数を崩す（二つ、四つ、長さ不揃い）
- [ ] **見出し直後の太字一文** → 外すか具体に差し替える
- [ ] **題がスローガン**になっていないか → 主題を名指す名詞句に
- [ ] **留保の連続**（終盤に「まだわからない」「言い切れない」が固まる）→ 一つに絞る
- [ ] **数字の几帳面な列挙**（「4本、3本、6個」）→ 一部を地の文に溶かす
- [ ] **二倍ダッシュ（——）**
- [ ] **「すべき」「絶対に」**などの断定語
- [ ] **進行の実況**（「〜をもう少し丁寧に見てみます」「ここで〜を考えてみます」）→ 削って中身から始める
- [ ] **読む人の反応の先取り**（「〜という疑いは当然出てくると思います」）→ 自分の判断として置き直す
- [ ] **書いている自分の実況**（「この場面を書いていて、ふと立ち止まる」）→ 削って次の文から入る
- [ ] **定義から入る段落の連続**（「◯◯という言葉があります。それは〜」が2回続く）
- [ ] **「ということでもある／でもあり」**の近接反復
- [ ] **同じ長さの場面の横並び** → ひとつかふたつに絞って細部を厚く
- [ ] **同じ助詞が重なって平板な文** → 語順を入れ替えるか文を割る
- [ ] **文の長さの均一**（「長い説明→短い着地」が等間隔）→ 極端に短い文を数か所挟む
- [ ] **推量語尾の均一**（確定していい事実にまで「〜だと思います」）→ 事実は言い切る
- [ ] **結びが三つ並べ**で終わっていないか

### 見分け方の基準

「誰が書いても同じ」文は、一文一文がすでに"まとめ"の顔をしている。迷いや言い淀みが構文に均されて消え、
同じ型が等間隔で戻ってくることで露呈する。
型があってもよい。ただし**発生源がその都度違う**こと（具体の匂い・自分の生活・その場の恥）。
読み終えて「この人にしか書けない」と思うか「よくできた説明だ」と思うかが分かれ目。
