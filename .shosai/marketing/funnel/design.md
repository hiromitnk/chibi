# 無料 → 有料の導線設計

## 全体像

```
X / 検索
  ↓
無料記事（共感 + 具体を1つだけ渡す）
  ↓  末尾リンク・プロフィール
有料記事（手順 + コピペ素材）
  ↓  末尾リンク
同シリーズの次の有料記事 → まとめ売り
```

## 無料記事の役割

無料記事は「宣伝」ではなく**単体で価値がある記事**にする。
ただし、渡すのは **具体策1つだけ**。残りは有料に置く。
無料で満足させて終わると次がない。逆に無料がスカスカだと信用が落ちる。ここのバランスが全て。

## 有料記事の無料パート（試し読み範囲）

構成は `../../content/CLAUDE.md` の「記事1本の構成」が正。ここでは繰り返さない。
導線として大事なのは一点：**「この記事で手に入るもの」を隠さない**こと。隠すと売れない。

## プロフィール文（3行）

```
デザイナー / 12TAPのクラフトビール店マネージャー。
診断はないけどグレーだと思っている側の人間として、
気合いではなく仕組みで仕事を回す方法だけを書いています。
```

## Xの固定ポスト

- 自己紹介 + 代表記事1本 + 「何を書く人か」を1ツイートに。
- 代表記事は、販売数が一番多い記事に**毎月入れ替える**。
