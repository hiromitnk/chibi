# note 新アカウント

決定日: 2026-09-09。既存アカウントとは切り離し、この事業専用に新設する。

## 作る前に決めること（オーナー判断）

| 項目 | 選択肢 | 備考 |
|---|---|---|
| 名義 | 本名 / ペンネーム | ADHDの話を一人称で書くなら、本業（デザイン・店）と切り離せるペンネームが安全。本名は信用が乗るが、クライアントや店のスタッフに読まれる前提になる |
| note ID（URL） | 英数字、後から変更不可 | 短く・打ちやすく・事業名と一致させる |
| 表示名 | 日本語可、後から変更可 | ID と揃えなくていい |
| 有料販売 | 本人確認＋振込口座の登録が必要 | 最初の有料記事を出す前に済ませる。審査に日数がかかる場合がある |

### 名前の候補（事業のタグラインから）

- **仕組みで殴る**（ミッションそのまま。ID: `shikumi`, `shikumi-de-naguru`）
- **気合いでは直らない**（入口記事のタイトルと同じ。ID: `kiai-nashi`）
- **グレーの書斎**（`.shosai` と対応。ID: `gray-shosai`）
- 中立なペンネーム＋肩書き（例：「〇〇｜仕組みで殴る人」）

「殴る」は強い語なので、表示名に入れるか一言だけ迷う。プロフィール文には入れていい。

## 作った直後にやること（順番固定）

1. プロフィール3行を入れる（`funnel/design.md` の文面）
2. ヘッダー画像とアイコン（Hiromiさんがデザイナーなので自作。他のADHD系noteと並んだとき一目で違うもの）
3. **無料の入口記事を1本**公開（「診断はない。それでも毎日つまずいている人へ」）
   → プロフィールに固定
4. 本人確認・振込口座の登録を申請（有料記事の前に済ませる）
5. 無料記事をもう1本
6. **有料記事1本目**（S1 から。手順とコピペ素材があるもの）
7. X の固定ポストにプロフィールと入口記事を貼る

有料記事を出す前に無料2本を置くのは、「何者か」が見えない状態で500円を要求しないため。
