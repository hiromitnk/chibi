### 自己紹介ページ・固定記事用（長文版）

```
出発の10分前に「あと5分」と思って、気づいたら家を出る時刻を過ぎている。
傘は年に何本もなくす。封筒は開けられないまま机の端に積まれていく。
買った瞬間に満足して、開けていない箱が部屋の隅にある。
夜、「今日も何もできなかった」と思いながらスマホを持ったまま床に座っている。

そういう人、いると思うんですけど。私です。ADHDです。

気合いで直そうとした期間が長くありました。手帳を買い、アプリを乗り換え、
「明日から」を何十回も言いました。直りませんでした。

直らなかったので、やめました。代わりに、忘れる前提・遅れる前提・飽きる前提で、
生活のほうを組み直すことにしました。鍵の置き場所、時計の見方、封筒の処理、
買い物の間に挟むもの。ひとつずつ、仕組みにしました。

このnoteには、その仕組みだけを書きます。

- 医療の話はしません。私は医療者ではないし、診断や治療について言えることはありません。
- 「治った」とも「改善した」とも書きません。今もたまにやらかします。ただ、九割くらいは回っています。
- 書くのは「私の場合はこうだった」という工夫と、その手順です。

仕事は普通に働いています。忘れると困る仕事です。だからこそ仕組みを作らざるを得なかった、
というところがあります。記事の例に、たまに現場の話が出てきます。

しんどい日は、読まなくていいです。仕組みは逃げません。
```

## 作る前に決めること（決定済み。記録として残す）

| 項目 | 選択肢 | 備考 |
|---|---|---|
| 名義 | 本名 / ペンネーム | ADHDの話を一人称で書くなら、本業（デザイン・店）と切り離せるペンネームが安全。本名は信用が乗るが、クライアントや店のスタッフに読まれる前提になる |
| note ID（URL） | 英数字、後から変更不可 | 短く・打ちやすく・事業名と一致させる |
| 表示名 | 日本語可、後から変更可 | ID と揃えなくていい |
| 有料販売 | 本人確認＋振込口座の登録が必要 | 最初の有料記事を出す前に済ませる。審査に日数がかかる場合がある |

### 名前の候補（事業のタグラインから）

- **仕組みで殴る**（ミッションそのまま。ID: `shikumi`, `shikumi-de-naguru`）
- **気合いでは直らない**（入口記事のタイトルと同じ。ID: `kiai-nashi`）
- **グレーの書斎**（`.shosai` と対応。ID: `gray-shosai`）
- 中立なペンネーム＋肩書き（例：「〇〇｜仕組みで殴る人」）

「殴る」は強い語なので、表示名に入れるか一言だけ迷う。プロフィール文には入れていい。

## 作った直後にやること（順番固定）

1. プロフィール3行を入れる（`funnel/design.md` の文面）
2. ヘッダー画像とアイコン（Hiromiさんがデザイナーなので自作。他のADHD系noteと並んだとき一目で違うもの）
3. **無料の入口記事を1本**公開（「診断はない。それでも毎日つまずいている人へ」）
   → プロフィールに固定
4. 本人確認・振込口座の登録を申請（有料記事の前に済ませる）
5. 無料記事をもう1本
6. **有料記事1本目**（S1 から。手順とコピペ素材があるもの）
7. X の固定ポストにプロフィールと入口記事を貼る

有料記事を出す前に無料2本を置くのは、「何者か」が見えない状態で500円を要求しないため。
