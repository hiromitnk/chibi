# シリーズ／マガジン設計

## 基本方針

単発記事は流れて消える。**シリーズにして、1本買った人が次を買う**構造にする。
noteのマガジン機能で束ね、各記事の末尾から相互に送る。

## シリーズ案

### S1「気合いでは直らないので、仕組みで殴る」（主力・有料）
時間感覚・着手・忘れ物・衝動買い・過集中。ADHDライフハックの本線。
- 想定: 10〜12本。単価500円。まとめ売りの核。

### S2「削られた日の戻し方」（有料・一部⚠）
感覚の消耗、気分の落差、自責のループ。相談窓口を必ず入れる区画。
- 想定: 4〜5本。ここは慎重に、でも一番読まれる可能性がある。

### S3「現場で覚えた」（差別化・有料）
デザイン受託と12TAPの店で作った仕組み。他のADHD系noteにない**例の出どころ**。
- 想定: 5〜6本。主題はあくまで場面、現場は例。

### S4「入口」（無料）
自己紹介、方針、共感で入ってS1に送る。
- 想定: 無料6本。

## 導線

```
S3（無料・拡散）→ プロフィール／固定ポスト → S1（有料・主力）
                                          ↘ S2（有料・独自性）→ まとめ売り
```

## まとめ売り（3本目の有料記事を出したあとに検討）

- 3本セット 1,200円（単品1,500円 → 300円お得）
- マガジン購読 月額500円は、**月2本以上の公開ペースが安定してから**。
  ペースが崩れると信用を落とすので、当面は単品売り一本でいく。
