# シリーズ／マガジン設計

## 基本方針

単発記事は流れて消える。**シリーズにして、1本買った人が次を買う**構造にする。
noteのマガジン機能で束ね、各記事の末尾から相互に送る。

## シリーズ案

### S1「仕組みで殴る仕事術」（主力・有料）
段取り・締切・受発注まわり。デザイン受託の実例で書ける。最も購買動機が強い。
- 想定: 8〜10本。単価500円。まとめ売り候補。

### S2「忘れる前提の店舗オペ」（差別化・有料）
飲食店マネジメントの実例。他のADHD系noteとほぼ被らない**Hiromiさん固有の領域**。
- 想定: 5〜6本。ここが「この人から買う理由」になる。

### S3「グレーの生活設計」（入口・無料多め）
家・持ち物・お金・人間関係。共感で入って、S1/S2に送る役割。
- 想定: 無料6本 + 有料2本。

## 導線

```
S3（無料・拡散）→ プロフィール／固定ポスト → S1（有料・主力）
                                          ↘ S2（有料・独自性）→ まとめ売り
```

## まとめ売り（3本目の有料記事を出したあとに検討）

- 3本セット 1,200円（単品1,500円 → 300円お得）
- マガジン購読 月額500円は、**月2本以上の公開ペースが安定してから**。
  ペースが崩れると信用を落とすので、当面は単品売り一本でいく。
