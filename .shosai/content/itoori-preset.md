# itoori プリセット（この事業用）

書斎から `itoori` を呼ぶときは、このファイルの内容をそのまま渡す。
本家の既定値を、500円のnote記事に合わせて上書きする。

## つまみ（固定）

| つまみ | 値 | 理由 |
|---|---|---|
| 調べ方 | **手持ちの知識だけ**（例外あり、下記） | 素材は書き手の実務体験。外部資料で薄めない |
| 深さ | **あっさり（調査1周＋見直し1回）** | 3000〜5000字の体験記事に3周は過剰。段7で削る |
| 論旨 | あなたの指示をふくらませる | 本家既定のまま |
| トーン | 親しみやすく品のある語り口で | 本家既定のまま。細部は `voice.md` |
| 組み立て | **エッセイとして** | 一人称の実感が主役 |
| 揺らぎ | **少し揺らして** | `voice.md` の「温度に段差」を効かせる |
| 文章量 | ほどよい量で（3000〜5000字） | 本家既定のまま |
| 途中の相談 | おまかせ | 本家既定のまま |

## 「調べ方」の例外（コスト管理）

ウェブ版itoori（外部ツール）は1本あたり数十回の検索を回し、数百円〜千円弱かかる。
うちは**その逆**を狙う。原則ゼロ検索、必要なときだけ最小限。

- **原則**：検索しない。素材は書き手の体験と、すでに `persona.md` に確定している事実だけ。
- **例外**：本文で実在の第三者（実名・作品・経歴）を引用する場合に限り、**事実確認のための
  検索を1〜3回だけ**行ってよい。目的は「話を広げる」ことではなく「書いてあることが
  合っているか裏取りする」こと。裏取りできなかった具体的な数字・年齢等は本文に入れない
  （ぼかすか削る）。検索の回数と裏取りの結果は、決定ログに一言残す。
- 深さ（あっさり＝調査1周＋見直し1回）は例外を使っても変えない。裏取りは段1-2の
  「外向き」1周の中で完結させ、周を増やさない。

## 段0 に固定で渡す

- **話者**：ADHD当事者。一人称。完全匿名。実務は「仕事の場面」として一般化した例でのみ出す。
  業種・店名・地名など特定できる情報は出さない。観察者にならない。最後まで動かさない。
- **かたち**：④体験から立ち上げる
- **語り口の境界**（段4）：無料／有料の境界に置く。前＝寄り添い、後＝実務調。締めで寄り添いに戻す。
  詳細は `voice.md` の配分ルール。

## 段6 に追加で渡す点検

`references/checklists.md` の観点5（事実・因果・効能の断定）を必ず回し、
さらに `CLAUDE.md` の「公開前チェック」A項（安全）を段6の各周で照合する。

## writer-profile との優先順位

`itoori/references/writer-profile.md` が埋まったら、そちらが `voice.md` より優先。
埋まるまでは `voice.md` が語り口の正。
