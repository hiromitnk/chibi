# seikyu — 請求書・見積書ツール

Misoca の代わりに使う、1人用の請求書ツール。ビルド不要の静的ウェブアプリ。

- 請求書の作成・編集・複製・状態管理（下書き / 発行済 / 入金済）
- 定期請求（毎月・3か月ごと・毎年など）。アプリを開いたときに、発行日が来た分を自動で作成（取りこぼし分もまとめて）
- 件名・品目・備考に `{ym-1}` などの差し込み（下表）
- 請求書と同じ内容の見積書（「見積書を作成（2週間前）」ボタン。日付・番号は変更可）
- インボイス制度対応（登録番号、税率ごとの対象額と消費税額、8%は※表示）、源泉徴収
- PDF はブラウザ内で生成してダウンロード（A4、IPAゴシック埋め込み）

## 起動

フォントを fetch で読むので、ファイルを直接開く（file://）のではなく、ローカルサーバー経由で開く。

```sh
cd seikyu
python3 -m http.server 8000
# ブラウザで http://localhost:8000
```

静的ファイルだけなので、GitHub Pages / Vercel / Netlify などにそのまま置いても動く。

## データの保存場所（大事）

データは **そのブラウザの localStorage** に保存される。サーバーには送られない。

- 別のブラウザ・別のPCでは見えない
- ブラウザのサイトデータを消すと消える
- → **設定 → バックアップ** で JSON を書き出しておくこと。読み込みで復元できる

定期請求の自動作成は「アプリを開いたとき」に動く。開かない間に発行日が過ぎても、次に開いたときにまとめて作られる。

## 差し込みできる文字

基準は発行日の月。件名・品目名・備考で使える。

| 書き方 | 例（2026年1月25日発行） |
|---|---|
| `{ym}` / `{ym-1}` / `{ym+1}` | 2026年1月 / 2025年12月 / 2026年2月 |
| `{year}` `{year-1}` | 2026 / 2025 |
| `{month}` `{month-1}` `{month+1}` | 1 / 12 / 2 |
| `{MM}` | 01 |
| `{lastday}` `{lastday-1}` | 31 / 31（前月の末日） |
| `{date}` | 2026年1月25日 |

前月分の請求は `{ym-1}分` と書くと年またぎも正しくなる（`{year}年{month-1}月` だと1月に年がずれる）。

```sh
cd seikyu

```
