# seikyu — 請求書・見積書ツール

Misoca の代わりに使う、1人用の請求書ツール。ビルド不要。

- 請求書の作成・編集・複製・状態管理（下書き / 発行済 / 入金済）
- 定期請求（毎月・3か月ごと・毎年など）。アプリを開いたときに、発行日が来た分を自動で作成（取りこぼし分もまとめて）
- 件名・品目・備考に `{ym-1}` などの差し込み（下表）
- 請求書と同じ内容の見積書（「見積書を作成（2週間前）」ボタン。日付・番号は変更可）
- インボイス制度対応（登録番号、税率ごとの対象額と消費税額、8%は※表示）、源泉徴収
- PDF はブラウザ内で生成してダウンロード（A4、IPAゴシック埋め込み）
- Vercel に置けば、どの端末からも同じデータで使える（パスワードでログイン）

## Vercel に置く（どの端末からも使う）

データはサーバー（Upstash Redis）に保存し、パスワード1つでログインする。スマホ・PC どちらからでも同じデータ。

1. **プロジェクトを作る**：vercel.com → Add New → Project → `hiromitnk/chibi` を Import
   - **Root Directory** を `seikyu` にする（Edit から選ぶ）
   - Framework Preset は **Other**。Build Command などは空のままでよい
2. **保存先を足す**：できたプロジェクトの **Storage** タブ → **Upstash**（Redis）を作成してこのプロジェクトに Connect
   - 無料プランで足りる。接続すると `KV_REST_API_URL` / `KV_REST_API_TOKEN`（または `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`）が自動で入る
3. **パスワードを決める**：Settings → Environment Variables に `SEIKYU_PASSWORD` を追加
   - 公開URLなので、長め（16文字以上）のパスワードに。変えると全端末がログアウトされる
4. **Deployments → 最新の … → Redeploy**（環境変数を反映するため）
5. 出てきた URL を開いてログイン。スマホはホーム画面に追加しておくとアプリっぽく使える

### 最初のデータの移し方

- ローカルで使っていたデータがある場合：そのブラウザで Vercel の URL を開いてログインすると、サーバーが空なら自動でそのデータが上がる
- 別のブラウザだった場合：ローカル版で「JSON を書き出す」→ Vercel 版の設定で「JSON を読み込む」

### 同期のしくみ

- 保存のたびにサーバーへ送る。右上に「同期済み / 保存中… / オフライン・未送信」
- 電波が無いときはブラウザに控えておき、つながったら送る（右上の表示を押しても送り直す）
- アプリに戻ってきたとき、別の端末で変わっていれば読み込み直す
- 2台で同時に変更してぶつかったときは、どちらを残すか確認が出る
- サーバーには **1日1つ、その日最初の変更より前の内容** が 90 日残る（設定 → 同期とサーバーの控え から書き出し・復元）

## ローカルで使う（サーバーなし）

```sh
cd seikyu
python3 -m http.server 8000
# ブラウザで http://localhost:8000
```

api が無い置き場所では自動で「このブラウザだけに保存」モードになる。データは localStorage（ブラウザのデータを消すと消える）なので、設定 → バックアップで JSON を書き出しておくこと。

定期請求の自動作成は「アプリを開いたとき」に動く。開かない間に発行日が過ぎても、次に開いたときにまとめて作られる。

## 差し込みできる文字

基準は発行日の月。件名・品目名・備考で使える。

| 書き方 | 例（2026年1月25日発行） |
|---|---|
| `{ym}` / `{ym-1}` / `{ym+1}` | 2026年1月 / 2025年12月 / 2026年2月 |
| `{year}` `{year-1}` | 2026 / 2025 |
| `{month}` `{month-1}` `{month+1}` | 1 / 12 / 2 |
| `{MM}` | 01 |
| `{lastday}` `{lastday-1}` | 31 / 31（前月の末日） |
| `{date}` | 2026年1月25日 |

前月分の請求は `{ym-1}分` と書くと年またぎも正しくなる（`{year}年{month-1}月` だと1月に年がずれる）。

## テスト

```sh
cd seikyu
node test/pdf-node-test.js        # 金額計算と PDF（test/out/ にサンプル出力）
node test/recurring-node-test.js  # 定期請求の日付計算・差し込み
```
