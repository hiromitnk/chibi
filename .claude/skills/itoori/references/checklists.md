# 点検リスト

## 段6 ｜ 見直しの4観点

感想を書かない。**箇所を名指しし、原文を引用する。**

### 1. テーゼの伝達 ― どこで弱まるか
- 主張が具体で支えられている箇所と、支えを失っている箇所を分けて名指す。
- とくに **終盤の留保表明**に注意する。主張の急所（実効性・検証可能性）に触れる
  留保が連続すると、読者は「結局わからないんだな」で持ち帰る。
- 不利な材料は、迷いとして放置されているか、主張の土台に作り替えられているか。
  放置されていれば書き直す。

### 2. 論立てと寄り道の評価
- テーゼに奉仕していない段落を特定する。
- 意図的な余剰（段3で「影として残す」と決めたもの）は残してよい。
- 「気配として匂わせる」と決めたものが、一段落を割いて前景化していないか。
  していれば削るか一言に落とす。

### 3. 誤読・条件化のリスク
- 抜き出したときに主張を条件付きにしてしまう一文を探す。
- 「〜とも言い切れません」「〜は外から見えません」の類は、
  そこで止めず、なぜそれでも主張が立つかまで書き切る。

### 4. 文体・運びの崩れ
- 折り目（大きく曲がる箇所）は一箇所に絞れているか。二箇所以上あれば往復になる。
- 二倍ダッシュ（——）の残存
- 説明なしに登場する固有名・業界語
- 100字超の頭でっかちな文
- 同じ比喩の一文内での反復

### 5. 事実・因果・効能の断定
- 診断名や属性を読者に断定している文（「あなたは〜だ」「〜な人は必ず〜」）
- 治る・改善する・効く、など効果を約束する語
- 「〜だから〜になる」の因果を、根拠なしに一般化している文
- 「ゼロにした」「必ず」「絶対」などの誇大表現
- 医学・法律・金銭に関わる助言を、専門家でない話者が断定している箇所
見つけたら、主語を書き手の体験に戻すか、削る。

## 段6 ｜ 成果物制作型（段0のかたち②）の点検軸

手紙・挨拶文・告知など、成果物そのものを差し出す場合は、上の4観点を使わない。
テーゼが伝わったかではなく、**その成果物として生きているか**で読む。

### 1. 声が割れていないか
説明する声が、語りかける声の上に乗っている箇所を名指す。
「なぜこの言葉が効くか」の注釈、概念の対比構造の図式化、問いを立てて論駁する運び——
これらが混じった瞬間、隣に座っていた人が一歩引いて分析を始めたように読める。

### 2. 話者が動いていないか
段0で決めた話者（当事者／実務者／観察者）から外れた文を探す。
一箇所でも外れると、その成果物は誰の言葉でもなくなる。

### 3. 具体が報告になっていないか
同じ長さの場面が横に並んでいたら、それは描写ではなく事例の列挙。
ひとつかふたつに絞り、その分だけ細部（音・匂い・体の動き）を厚くする。

### 4. 外形が壊れていないか
成果物の体裁に属さないもの（末尾の参照欄、見出し付きの出典リスト、
本文から浮いた強調表示）が付いていないか。付いていれば外すか、地の文に溶かす。

## 段7 ｜ AI臭さの摘発

**実際に数える。** 印象で「くどい」と書かない。
**そして数えたら直す。**摘発リストを出しただけで原稿に手を入れないのは、この段の失敗。

- [ ] **否定→肯定の対比**（「Aではありません。Bです」）が何箇所あるか
      → 6箇所以上なら 2箇所に絞る。他は言い切りか具体描写に開く。
- [ ] **「という」** の回数 → 20回超ならラベル貼りが目立っている。半分は直接つなげる。
- [ ] **三つ並べ**（名詞を3つ列挙して締める）の回数
- [ ] **見出し直後の太字一文** → 位置も型も編集テンプレそのもの。外すか具体に差し替える。
- [ ] **タイトルがスローガン**になっていないか → 主題を名指す名詞句に替える。
- [ ] **保留の表明が近接して連続**していないか → 賢さを演じる自己言及に寄る。一方に絞る。
- [ ] **数字の几帳面な列挙**（「4本、3本、6個、9項目」）→ 整理された報告書の拍になる。
      一部を地の文の描写に溶かす。
- [ ] 二倍ダッシュ（——）
- [ ] 「すべき」「絶対に」などの断定語
- [ ] **進行アナウンス**（「〜をもう少し丁寧に見てみます」「ここで〜を考えてみます」）
      → 中身に入る前の実況。削って、いきなり中身から始める。
- [ ] **読者の反応の先取り**（「〜という疑いは当然出てくると思います」）
      → 自分の判断として置き直す。
- [ ] **執筆行為の実況**（「この場面を書いていて、ふと立ち止まる」「ここで話は急に〜に触れる」）
      → 文章上の移動を語っている。削って、次の文からそのまま入る。
- [ ] **「◯◯という言葉があります。それは〜を指します」の定義開始**が2回以上連続していないか
- [ ] **「ということでもある／ということでもあり」** の近接反復
- [ ] **同じ長さの場面の横並び**（一文一文が同じ長さで淡々と並ぶ事例の列挙）
      → ひとつかふたつに絞り、その分だけ細部（音・匂い・体の動き）を厚くする。
- [ ] **一文に同じ助詞が重なって平板**な文（「は」「の」「が」「て」が詰まる）→ 語順を入れ替えるか文を割る
- [ ] **文長の均一さ**（「長い説明文→短い着地」が等間隔）→ 極端に短い文を数か所挟んで波を作る
- [ ] **推量語尾の均一**（「〜だと思います」「〜はずです」が、確定していい事実にまで付いている）
      → 事実は言い切り、本当に不確かな解釈だけ残す
- [ ] **結びが三拍子**で終わっていないか → 数を崩す

### 見分け方の基準

「誰が書いても同じ」文は、**一文一文がすでに"まとめ"の顔をしている**。
迷いや言い淀みが構文に均されて消え、同じ型が等間隔で戻ってくることで露呈する。

型があってもよい。ただし**発生源がその都度違う**こと（具体の匂い・自分の生活・その場の恥）。
読み終えて「この人にしか書けない」と思うか「よくできた説明だ」と思うかが分かれ目。
